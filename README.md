# To-Do List Web App

## Overview

To-Do List Web App is a simple task management application built using HTML, CSS, and JavaScript. The application allows users to create, track, and manage daily tasks through an intuitive interface.

Users can add new tasks, mark tasks as completed, and remove tasks from the list, providing a lightweight solution for organizing personal activities and improving productivity.

## Features

* Add tasks dynamically
* Mark tasks as completed
* Delete tasks from the list
* Clean and responsive user interface
* Real-time interaction using JavaScript

## Tech Stack

* HTML5
* CSS3
* JavaScript (Vanilla JS)

1. Clone the repository.
